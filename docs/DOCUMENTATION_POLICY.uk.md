# Політика документації

Ця політика є нормативною для документації репозиторію.

## Мова та імена файлів

Англійська версія є канонічною для машинного тлумачення. Кожен нормативний
документ для користувачів має український відповідник `NAME.uk.md` у тому
самому каталозі. Обидва файли оновлюються в одному коміті та мають містити
однакові вимоги й критерії приймання. Ідентифікатори, команди, шляхи, версії,
поля та теги не перекладаються.

`AGENTS.md` навмисно існує лише англійською, щоб автоматизація мала одне
однозначне джерело інструкцій.

## Що є нормативним

Політики, регламенти, обов'язкові контрольні списки, правила участі, рішення
про міграцію, release-процедури, схеми та публічні експлуатаційні інструкції є
нормативними. Зміна не завершена без перекладу, робочих навігаційних посилань,
запису в changelog або потрібного підвищення версії процесу.

Якщо переклади суперечать один одному, для виконання застосовується англійська
версія. Розбіжність однаково є дефектом і має бути усунена до release процесу
або продукту.

## Формулювання вимог і статус

`MUST`, `MUST NOT`, `SHOULD` та `MAY` використовуються у звичайному
нормативному значенні. Документи мають відрізняти реалізовану поведінку від
погодженої цілі. Заплановані вимоги v1 не можна рекламувати як наявні в
поточному опублікованому пакеті 0.1.x.

Історичні інструкції після заміни мають починатися з помітного повідомлення
про legacy-статус. Інструкції для вже опублікованого тегу не переписуються
мовчки.

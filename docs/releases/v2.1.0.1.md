# iros2j 1.0.1 — Debian 13 ARM64

Git release tag: `v2.1.0.1`.

This release replaces the legacy `iros2-0` monolith with individual
`iros2j-*` Debian packages for ROS 2 Jazzy. It is distributed as a signed APT
repository snapshot for native Debian 13 Trixie ARM64 systems.

The release assets include the repository bundle, archive key, checksums,
exact source lock, component inventory, SBOM, and native gate evidence.
AMD64, Docker, QEMU, and VINS-NEO validation are outside this release.

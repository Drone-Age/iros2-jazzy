# iros2j 1.0.2 — Debian 13 ARM64

Git release tag: `v2.1.0.2`.

Виправний реліз для Debian 13 Trixie ARM64. Він виключає Python bytecode,
створений на build-host, з Debian-пакетів і вимагає fail-fast ROS/RViz smoke
перевірку після встановлення з опублікованого підписаного APT snapshot.

Реліз залишається лише native ARM64. AMD64, Docker, QEMU та перевірка VINS-NEO
не входять до scope.

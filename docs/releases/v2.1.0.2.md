# iros2j 1.0.2 — Debian 13 ARM64

Git release tag: `v2.1.0.2`.

Corrective release for Debian 13 Trixie ARM64. It excludes build-host Python
bytecode from Debian packages and requires fail-fast ROS/RViz smoke
verification after installation from the published signed APT snapshot.

The release remains native ARM64 only. AMD64, Docker, QEMU and VINS-NEO
validation are outside scope.

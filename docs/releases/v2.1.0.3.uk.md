# Коригувальний випуск iros2j 1.0.3

Версія продукту: `1.0.3`

Git-тег: `v2.1.0.3`

Версія процесу: `1.6.0`

Платформа: Debian 13 Trixie ARM64

Цей незмінний коригувальний випуск пакує точні зафіксовані у source lock
development- і runtime-компоненти Fast CDR `2.2.7` та Fast DDS/fastrtps
`2.14.6`, проти яких зібрано пакети ROS 2 Jazzy `rmw_fastrtps_*`. Для цього
snapshot він усуває помилкову залежність від Debian 13
`libfastrtps-dev 3.1.2+ds-1`; опублікований випуск `v2.1.0.2` не змінюється.

Native- та post-release-gate встановлюють лише створений підписаний APT
snapshot, конфігурують і збирають downstream CMake consumer через
`find_package(fastcdr 2.2)` і `find_package(fastrtps 2.13)`, а також виконують
репрезентативний Fast DDS RMW smoke test у чистому shell.

Випуск залишається лише native ARM64. AMD64, Docker, QEMU, перевірка VINS-NEO
та створення штучного compatibility-файлу не входять до scope.

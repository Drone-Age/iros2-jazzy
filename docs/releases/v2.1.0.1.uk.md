# iros2j 1.0.1 — Debian 13 ARM64

Git release tag: `v2.1.0.1`.

Цей release замінює legacy-моноліт `iros2-0` окремими Debian-пакетами
`iros2j-*` для ROS 2 Jazzy. Він поширюється як snapshot підписаного APT
repository для нативних систем Debian 13 Trixie ARM64.

Release assets містять repository bundle, archive key, checksums, exact source
lock, component inventory, SBOM та native gate evidence. AMD64, Docker, QEMU і
перевірка VINS-NEO не входять до цього release.

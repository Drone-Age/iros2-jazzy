# iros2j 1.0.3 corrective release

Product version: `1.0.3`

Git tag: `v2.1.0.3`

Process version: `1.6.0`

Platform: Debian 13 Trixie ARM64

This immutable corrective release packages the exact source-locked Fast CDR
`2.2.7` and Fast DDS/fastrtps `2.14.6` development and runtime payloads that
the ROS 2 Jazzy `rmw_fastrtps_*` packages were built against. It replaces the
incorrect dependency on Debian 13 `libfastrtps-dev 3.1.2+ds-1` for this
snapshot; it does not modify the published `v2.1.0.2` release.

The native and post-release gates install only the generated signed APT
snapshot, configure and build a downstream CMake consumer using
`find_package(fastcdr 2.2)` and `find_package(fastrtps 2.13)`, and run the
representative Fast DDS RMW smoke test in a clean shell.

The release remains native ARM64 only. AMD64, Docker, QEMU, VINS-NEO
validation, and compatibility-file fabrication are outside scope.

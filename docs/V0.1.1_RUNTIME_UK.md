# IROS2_0 v0.1.1: запуск і перевірка

## Нативна збірка на Raspberry Pi 5

Релізний `.deb` збирається безпосередньо на Debian 13 ARM64:

```bash
cd ~/iros2_0
./scripts/native/install-dependencies.sh
./scripts/native/build-rpi.sh
./scripts/native/build-package.sh
```

Готовий пакет і `SHA256SUMS` з'являються у `artifacts/`.

## Команди кінцевого обладнання

Після `apt install` пакетні wrappers працюють у чистому non-login shell:

```bash
env -i HOME="$HOME" PATH=/usr/bin:/bin \
  bash --noprofile --norc -c 'ros2 --help'
env -i HOME="$HOME" PATH=/usr/bin:/bin QT_QPA_PLATFORM=offscreen \
  bash --noprofile --norc -c 'rviz2 --help'
```

Wrappers завантажують `/opt/iros2_0/jazzy/setup.bash` лише для процесу
команди. Вони не змінюють конфігурацію shell користувача.

## Розробка та overlays

Повне середовище можна активувати вручну:

```bash
source /opt/iros2_0/jazzy/setup.bash
```

Або один раз явно додати активацію до поточного `~/.bashrc`:

```bash
iros2-enable-bash
```

Команда ідемпотентна. Debian maintainer scripts не змінюють
`/etc/bash.bashrc`, `/home/*/.bashrc` або `/root/.bashrc`.

Для overlay workspace спочатку завантажте underlay, виконайте
`colcon build`, а потім завантажте `install/setup.bash`.

## Docker runtime

Runtime stage використовує пакетний entrypoint:

```bash
docker build --target runtime -t iros2-0:0.1.1 .
docker run --rm iros2-0:0.1.1 ros2 --help
```

Entrypoint завантажує `/opt/iros2_0/jazzy/setup.bash` і виконує передану
команду через `exec "$@"`.

## Видалення

```bash
sudo apt purge iros2-0
test ! -e /usr/bin/ros2
test ! -e /usr/bin/rviz2
test ! -e /usr/bin/iros2-enable-bash
test ! -e /usr/lib/iros2-0/docker-entrypoint.sh
```
